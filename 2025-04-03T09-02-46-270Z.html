What is the yoga layout?

Yoga Layout: A Cross-Platform Flexbox Engine

Yoga is an open-source cross-platform layout engine that implements Flexbox for UI development. It was created by Meta (Facebook) to provide fast and efficient layout calculations for various platforms, including mobile, web, and desktop applications.

🔹 GitHub Repo: facebook/yoga
🔹 Written In: C++
🔹 Bindings Available For: JavaScript, TypeScript, Python, Rust, Go, and more.

🔹 Why Use Yoga?

  1. Implements CSS Flexbox: Brings the power of CSS Flexbox to non-web environments.

  2. Lightweight & Fast: Designed for high-performance rendering in UI frameworks.

  3. Cross-Platform: Works on Android, iOS, React Native, WebAssembly, and more.

  4. Low-Level Control: Can be embedded in game engines, terminal UIs, or native apps.

  5. Used in React Native: React Native’s layout system is powered by Yoga.

🔹 How Does Yoga Work?

Instead of relying on a browser's CSS engine, Yoga computes layouts independently using a C++ implementation of Flexbox rules. It takes a tree of nodes (like a UI structure) and calculates the sizes/positions based on Flexbox rules.

Example: Creating a Flexbox Layout with Yoga

Let's use JavaScript (Node.js) with yoga-layout:

🔹 Install Yoga for Node.js 

bash
npm install yoga-layout

🔹 Example: Creating a Simple Flexbox Layout 

javascript
const yoga = require('yoga-layout');

// Create a root node
const root = yoga.Node.create();
root.setWidth(500);
root.setHeight(300);
root.setFlexDirection(yoga.FLEX_DIRECTION_ROW); // Like "display: flex; flex-direction: row;"

// Create a child node
const child = yoga.Node.create();
child.setWidth(100);
child.setHeight(100);
child.setMargin(yoga.EDGE_ALL, 10); // Add margin

// Attach child to root
root.insertChild(child, 0);

// Calculate layout
root.calculateLayout(500, 300, yoga.DIRECTION_LTR);

console.log(root.getComputedLayout()); // Output the calculated positions
console.log(child.getComputedLayout()); // Output child position

🔹 Where is Yoga Used?

  • React Native (Handles all layout calculations)

  • Component-based UI frameworks

  • Terminal-based UIs (TUI)

  • Game UI layouts (Unity, Unreal, etc.)

  • Cross-platform desktop applications

🔹 Should You Use Yoga?

✔ Yes, if you:

  • Need flexbox-style layouts outside of a browser.

  • Are working with React Native or embedded UI systems.

  • Want consistent UI layouts across platforms.

❌ No, if you:

  • Are just building for the web (use CSS Flexbox instead).

  • Don't need fine-grained control over layout calculations.

You can use Yoga Layout for flexbox-style layouts in a terminal UI (TUI) by combining it with a rendering library like Blessed or Ink (React for terminal).

🔹 Approach

  1. Use Yoga Layout to calculate flexible layouts.

  2. Render the computed layout inside a terminal UI framework like Blessed or Ink.

🔹 Method 1: Using Yoga with Blessed

bash
npm install blessed yoga-layout

javascript

root.setWidth(80);
root.setHeight(24);
root.setFlexDirection(yoga.FLEX_DIRECTION_ROW);

// Create a left panel
const leftPanel = yoga.Node.create();
leftPanel.setWidth(40);
leftPanel.setHeight(24);
leftPanel.setMargin(yoga.EDGE_ALL, 1);
root.insertChild(leftPanel, 0);

rightPanel.setFlexGrow(1);
rightPanel.setHeight(24);
rightPanel.setMargin(yoga.EDGE_ALL, 1);

const box1 = blessed.box({
  top: root.getComputedTop(),
  left: root.getComputedLeft(),
  width: leftPanel.getComputedWidth(),
  height: leftPanel.getComputedHeight(),

  border: { type: 'line' },
  style: { border: { fg: 'blue' } }

  left: rightPanel.getComputedLeft(),
  width: rightPanel.getComputedWidth(),

  border: { type: 'line' },
  style: { border: { fg: 'green' } }
});

screen.append(box2);
screen.render();

  • Yoga calculates the flexible layout.

  • Blessed renders the UI based on Yoga's computed positions.

  • The left panel has a fixed width.

  • The right panel flexes and fills the remaining space.

Do I have to set a specific width and height in yoga?

Do You Have to Set a Specific Width and Height in Yoga?

No, you don’t have to explicitly set a width and height in Yoga. Instead, Yoga provides flexbox properties that allow elements to dynamically size based on their content and parent container.

🔹 What Happens If You Don’t Set Width & Height?

If you don't define setWidth() and setHeight(), the node will:

  1. Shrink to fit its content (if no flex properties are set).

  2. Expand dynamically if flexGrow is enabled.

  3. Be constrained by its parent’s layout if a parent node defines width/height.

🔹 Example: Flexible Layout Without Fixed Width/Height 

javascript
const yoga = require('yoga-layout');

// Root node (container)
const root = yoga.Node.create();
root.setFlexDirection(yoga.FLEX_DIRECTION_ROW);
root.setWidth(500); // Fixed width, height can be dynamic

// Child node 1 (Fixed size)
const box1 = yoga.Node.create();
box1.setWidth(100);
box1.setHeight(100);
root.insertChild(box1, 0);

// Child node 2 (Flexible size)
const box2 = yoga.Node.create();
box2.setFlexGrow(1); // Expands to fill remaining space
box2.setHeight(100);
root.insertChild(box2, 1);

// Compute layout
root.calculateLayout(undefined, undefined, yoga.DIRECTION_LTR);

console.log('Box1:', box1.getComputedLayout());
console.log('Box2:', box2.getComputedLayout());

🔹 How to Make Elements Auto-Size?

Property Behavior
setWidth() / setHeight() Sets a fixed size.
setFlexGrow(1) Expands to fill remaining space.
setFlexShrink(1) Shrinks when necessary.
setAlignSelf(yoga.ALIGN_STRETCH) Stretches to fill parent’s height.

🔹 Example: Dynamic Height Using ALIGN_STRETCH 

javascript
const container = yoga.Node.create();
container.setWidth(300);
container.setHeight(400);
container.setFlexDirection(yoga.FLEX_DIRECTION_COLUMN);

const child = yoga.Node.create();
child.setFlexGrow(1); // Expands to fill available space
child.setAlignSelf(yoga.ALIGN_STRETCH); // Stretches to parent's height
container.insertChild(child, 0);

container.calculateLayout(undefined, undefined, yoga.DIRECTION_LTR);
console.log('Child layout:', child.getComputedLayout());

🔹 Conclusion

✔ No, you don’t need to set explicit width/height.
✔ Use Flexbox properties like flexGrow, flexShrink, and alignSelf to create dynamic layouts.
✔ If an element has no content and no explicit size, it may collapse to 0x0 size.

Does Blessed Support Flexbox Out of the Box?

No, Blessed does NOT support Flexbox natively. It relies on absolute positioning (top, left, width, height) and box models instead. However, you can combine Yoga Layout with Blessed to achieve Flexbox-like layouts in a terminal.

🔹 How Layout Works in Blessed

Blessed has a grid-like positioning system with properties like:

  • top, left, width, height (absolute positioning)

  • shrink (content-based sizing)

  • align, valign (text alignment, not Flexbox)

  • padding, margin (basic spacing)

🚫 What Blessed lacks:

  • No flexDirection (row / column layouts)

  • No flexGrow / flexShrink

  • No auto-spacing like CSS Flexbox

🔹 How to Add Flexbox to Blessed?

Since Blessed doesn’t have built-in Flexbox, you can use Yoga Layout to calculate positions dynamically, then apply them manually to Blessed elements.

Example: Using Yoga to Handle Flexbox in Blessed 

javascript
const blessed = require('blessed');
const yoga = require('yoga-layout');

// Create a root layout node
const root = yoga.Node.create();
root.setWidth(80);
root.setHeight(24);
root.setFlexDirection(yoga.FLEX_DIRECTION_ROW);

// Left panel (fixed size)
const leftPanel = yoga.Node.create();
leftPanel.setWidth(30);
leftPanel.setHeight(24);
root.insertChild(leftPanel, 0);

// Right panel (flexible)
const rightPanel = yoga.Node.create();
rightPanel.setFlexGrow(1); // Takes remaining space
rightPanel.setHeight(24);
root.insertChild(rightPanel, 1);

root.calculateLayout(80, 24, yoga.DIRECTION_LTR);

// Create Blessed screen
const screen = blessed.screen();
const box1 = blessed.box({
  top: 0,
  left: 0,
  width: leftPanel.getComputedWidth(),
  height: leftPanel.getComputedHeight(),
  content: 'Left Panel (Fixed)',
  border: { type: 'line' },
  style: { border: { fg: 'blue' } }

  border: { type: 'line' },
  style: { border: { fg: 'green' } }

screen.append(box2);

🔹 How to Replace Yoga + Blessed with JSX Components

We will:

  1. Use React-Blessed to handle the terminal UI in JSX.

  2. Use Yoga Layout inside JSX components to calculate positions.

  3. Render the result into Blessed elements dynamically.

1️⃣ Install Dependencies 

bash
npm install react react-blessed yoga-layout blessed

2️⃣ Create App.jsx

Here’s how you can replace your Yoga + Blessed setup with JSX components: 

jsx
import React, { useEffect, useState } from "react";
import { render } from "react-blessed";
import blessed from "blessed";
import yoga from "yoga-layout";

// Flexbox component using Yoga Layout
const FlexContainer = ({ children }) => {
  const [layout, setLayout] = useState(null);

  useEffect(() => {
    // Root Yoga Node (80x24)
    const root = yoga.Node.create();
    root.setWidth(80);
    root.setHeight(24);
    root.setFlexDirection(yoga.FLEX_DIRECTION_ROW);

    // Left panel (fixed size)
    const leftPanel = yoga.Node.create();
    leftPanel.setWidth(30);
    leftPanel.setHeight(24);
    root.insertChild(leftPanel, 0);

    // Right panel (flexible)
    const rightPanel = yoga.Node.create();
    rightPanel.setFlexGrow(1);
    rightPanel.setHeight(24);
    root.insertChild(rightPanel, 1);

    // Calculate layout
    root.calculateLayout(80, 24, yoga.DIRECTION_LTR);

    setLayout({
      leftPanel: {
        width: leftPanel.getComputedWidth(),
        height: leftPanel.getComputedHeight(),
      },
      rightPanel: {
        width: rightPanel.getComputedWidth(),
        height: rightPanel.getComputedHeight(),
        left: leftPanel.getComputedWidth(),
      },
    });
  }, []);

  if (!layout) return null;

  return (
    <>
      <box
        top={0}
        left={0}
        width={layout.leftPanel.width}
        height={layout.leftPanel.height}
        border={{ type: "line" }}
        style={{ border: { fg: "blue" } }}
      >
        Left Panel (Fixed)
      </box>
      <box
        top={0}
        left={layout.rightPanel.left}
        width={layout.rightPanel.width}
        height={layout.rightPanel.height}
        border={{ type: "line" }}
        style={{ border: { fg: "green" } }}
      >
        Right Panel (Flexbox)
      </box>
    </>
  );
};

// Main App Component
const App = () => {
  return (
    <FlexContainer />
  );
};

// Create Blessed Screen & Render App
const screen = blessed.screen();
render(<App />, screen);

✅ Uses JSX components instead of raw Blessed objects.
✅ Uses Yoga for layout calculations inside useEffect().
✅ Dynamically maps Yoga nodes to Blessed JSX elements.
✅ Automatically re-renders when layout updates.

✔ Write Terminal UI in JSX, making it easier to structure.
